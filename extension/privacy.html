bookmrkd Privacy Policy

Effective: 18 May 2026 · Extension version

bookmrkd (“we”, “the extension”) is a bookmark organization tool that runs in your browser. This policy describes what data is processed and where it goes.

Data we access

  • Bookmarks — titles, URLs, folder paths, and optional favicon data from Chrome’s bookmarks API or a file you import.
  • Settings — preferences, optional custom rules JSON, and an optional Gemini API key stored in chrome.storage on your device.

Offline mode (default)

In Offline mode, all analysis happens locally in your browser. No bookmark data is sent to bookmrkd servers — there are no bookmrkd servers. Nothing is uploaded to the internet.

Online mode (optional)

If you enable Online mode and save a Google Gemini API key, uncertain bookmarks are sent in small batches to Google’s Generative Language API. Each batch includes only page title and URL — not your full library, browsing history, or page content. Google’s privacy policy applies to that traffic: policies.google.com/privacy.

What we do not do

  • We do not sell your data.
  • We do not run analytics or advertising trackers in the extension.
  • We do not modify or delete your bookmarks automatically — you choose whether to import an exported HTML file.

Data storage

API keys and imported HTML (if used) are stored in chrome.storage.local. Settings sync via chrome.storage.sync if your browser sync is enabled. You can remove API keys in Settings → Danger zone.
