# bookmrkd — Chrome Extension

**Semantic Bookmark Organizer** by **[Minhajul Abedin](https://github.com/minhaj14d)** · [GPL-3.0](../LICENSE)

Dedupe, categorize, and export bookmarks. Offline-first with optional free Gemini assist.

→ **Main README:** [github.com/minhaj14d/bookmrkd](https://github.com/minhaj14d/bookmrkd)  
→ **Releases (ZIP / CRX):** [Releases](https://github.com/minhaj14d/bookmrkd/releases)  
→ **Build guide:** [RELEASE.md](../RELEASE.md)

## Install (development)

```bash
npm ci
```

Chrome → Extensions → Developer mode → **Load unpacked** → this folder.

## Commands

```bash
npm run lint
npm run typecheck
npm run version:sync
npm run pack              # ../release/bookmrkd-v*.zip
```
